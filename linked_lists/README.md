# Лабораторная работа № 4. Связные списки

Сборка и тесты в Ubuntu:

```bash
cmake -S linked_lists -B linked_lists/build -DCMAKE_BUILD_TYPE=Debug
cmake --build linked_lists/build --parallel
ctest --test-dir linked_lists/build --output-on-failure
linked_lists/build/list_demo
linked_lists/build/list_demo distance
linked_lists/build/list_demo mass
linked_lists/build/list_demo diameter
```

Односвязный список хранит указатели на первый и последний узлы. Вставка
в хвост выполняется за O(1), а версия с обходом работает за O(n).
При удалении хвоста обновляется указатель на последний узел. Удаление
единственного узла обнуляет оба указателя.

Двусвязный список использует два ограничителя. Вставка у границ и
удаление известного узла занимают O(1), поиск узла по значению — O(n).
В упорядоченном списке имён обход с конца может сократить число
сравнений для имён ближе к концу. Худшая сложность остаётся O(n).

У каждого узла списка планет три независимых ссылки для обхода по
расстоянию, массе и диаметру. Параметр командной строки выбирает цепочку.

Алгоритм Флойда обнаруживает цикл и находит его начало за O(n) времени
и O(1) дополнительной памяти. Для разрыва цикла обнуляется ссылка узла,
который ведёт обратно в начало цикла.
